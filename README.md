# Quiz — mathseide

Quiz pour iPad publiés sur https://mathseide.github.io/quiz/

- Chaque page de quiz est **chiffrée** : il faut le code du quiz pour l'ouvrir.
  Les codes ne sont jamais enregistrés ici.
- `outils/modele-quiz.html` : modèle de quiz (configuration en haut du fichier).
- `outils/chiffrer.py` : chiffre / déchiffre une page de quiz.
- `outils/Code.gs` : script Google Apps Script qui reçoit les résultats (mail + tableur).
